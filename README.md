# FIAP MLOps

Projeto desenvolvido durante a Pós-Tech em Machine Learning Engineering da FIAP.

Este repositório reúne as atividades, exercícios e projetos desenvolvidos ao longo das aulas de MLOps, Machine Learning e Engenharia de Dados.

## Conteúdos estudados

- Criação de ambientes virtuais com Python
- Organização de projetos de Machine Learning
- Ingestão e validação de dados
- Feature Engineering
- Transformação e normalização de dados
- Pipelines com Scikit-Learn
- Treinamento e avaliação de modelos
- Testes automatizados com Pytest
- Controle de versão com Git e GitHub
- Versionamento de dados com DVC
- Boas práticas de MLOps
- Automação de pipelines
- Deploy de modelos
